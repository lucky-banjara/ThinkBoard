MERN Notes Application

A full-stack notes management application built with the MERN stack (MongoDB, Express.js, React, and Node.js).

The project demonstrates the development of a modern web application from backend API development through to
frontend integration and deployment. It includes RESTful API design, MongoDB data persistence, CRUD operations,
middleware, rate limiting, responsive UI, and production deployment.
